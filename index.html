Live EDDN messages, separated by type.

A static GitHub Pages dashboard that listens to an EDDN WebSocket-compatible feed, groups each schema/message type into its own block, and filters every visible message as you type.

Feed endpoint

GitHub Pages cannot consume EDDN ZeroMQ directly, so this static app expects a browser-accessible EDDN WebSocket feed. The default endpoint is configurable in the URL with ?ws=....
